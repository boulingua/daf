*Eigenständig verfasste Modulübung; keine offizielle Prüfung oder vollständige GER-Einstufung. Die Punktwerte beschreiben nur die Leistung in diesen Aufgaben. Bei persönlichen Angaben sind erfundene Angaben erlaubt.*


**Aufgabe:** Sie hören **fünf Durchsagen** (einmal). Sind die
Aussagen richtig oder falsch? Kreuzen Sie an.

1. Ein Kilo Äpfel kostet 99 Cent. → R / F
2. Milch kostet über 2 Euro. → R / F
3. Eine Tasse Kaffee kostet 2 Euro. → R / F
4. Ein halbes Kilo Brot kostet 2,50 €. → R / F
5. Kasse 3 ist geschlossen. → R / F

**Punkte-Rubrik:** 1 Punkt pro richtige Antwort · 5 Punkte gesamt ·
bestanden ab 3 Punkten.

{{< details type="tip" title="Lösungen" role="key" >}}
1. R · 2. F · 3. R · 4. R · 5. F.

{{< /details >}}

{{< details title="Vorlesetexte — nur für Lehrkräfte" role="key" >}}

1. „Äpfel, ein Kilo für 99 Cent."

2. „Milch, ein Liter 1,29 €."

3. „Kaffee, eine Tasse 2 Euro."

4. „Brot, 500 Gramm, 2,50 €."

5. „Kasse 3 ist jetzt offen."

{{< /details >}}
