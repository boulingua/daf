DAF · BEWERTUNGSRASTER · A1–C1

</div>

Die offiziellen Bewertungsraster für **Schreiben** und
**Sprechen** auf den fünf Stufen — in einer einheitlichen
Tabellenform. Vollständig ausformulierte Skalen liegen in den
fünf YAML-Dateien unter
[`_resources/`](https://github.com/boulingua/daf/tree/main/_resources):
`format_a1.yml` bis `format_c1.yml`.

## Pass-Schwellen kompakt

| Stufe | Prüfungsmodell        | Max. Punkte         | Bestehen |
|-------|-----------------------|---------------------|----------|
| A1    | 4 Module in 1 Block   | 100 (4 × 25)        | 60 %     |
| A2    | 4 Module in 1 Block   | 100 (4 × 25)        | 60 %     |
| B1    | 4 Module modular      | je 100 pro Modul    | 60 % pro Modul |
| B2    | 4 Module modular      | je 100 pro Modul    | 60 % pro Modul |
| C1    | 4 Module modular      | je 100 pro Modul    | 60 % pro Modul |

## Skalen-Logik (B1 / B2 / C1)

Auf B1, B2 und C1 wird jede produktive Aufgabe (Schreiben /
Sprechen) entlang **fünf Dimensionen** auf einer **A–E-Skala**
bewertet. Die Skala ist absteigend:

| Stufe | Punkte | Bedeutung               |
|-------|--------|-------------------------|
| A     | 5      | voll erfüllt            |
| B     | 3,5    | überwiegend erfüllt     |
| C     | 2      | teilweise erfüllt       |
| D     | 0,5    | kaum erfüllt            |
| E     | 0      | nicht erfüllt           |

**KO-Regel:** Wird die Dimension **Erfüllung der Aufgabe** mit E
bewertet, ist die gesamte Aufgabe 0 Punkte — unabhängig von den
anderen Dimensionen.

## Schreiben — Dimensionen je Stufe

| Stufe | Dimensionen                                    |
|-------|------------------------------------------------|
| A1    | 1 Punkt pro richtig ausgefülltem Feld (Formular) + Inhaltspunkte (Kurzmitteilung) |
| A2    | Aufgabenerfüllung · Sprache (je A–E)           |
| B1    | Erfüllung · inhaltlicher Zusammenhang („Kohärenz“) · Wortschatz · Strukturen |
| B2    | Erfüllung · Wortschatz · Strukturen · Sprachebene („Register“) |
| C1    | Erfüllung · Kohärenz · Wortschatz · Strukturen · Register |

## Sprechen — Dimensionen je Stufe

|-------|---------------------------------------------------|
| A1    | je 1 Punkt für Vorstellen / Buchstabieren / Nummer (Teil 1) + Aufgabenerfüllung Teil 2/3 |
| A2    | Aufgabenerfüllung · Sprache · Aussprache (gesamt) |
| B1    | Erfüllung · Kohärenz · Wortschatz · Strukturen · Aussprache |
| B2    | Erfüllung · Kohärenz · Wortschatz · Strukturen · Aussprache |
| C1    | Erfüllung · Kohärenz · Wortschatz · Strukturen · Aussprache |

## A1 / A2 — Notenskala (Ergebnisskala)

| Punkte (von 100) | Prädikat (DE)          |
|------------------|------------------------|
| 90 – 100         | sehr gut               |
| 80 – 89          | gut                    |
| 70 – 79          | befriedigend           |
| 60 – 69          | ausreichend            |
| 0 – 59           | nicht bestanden        |

(Quelle: GER-Prüfung A1 *Prüfungsziele,
Testbeschreibung*, S. 7.)

## Modul-Verteilung in dieser Site

Pro Kurs (12 Einheiten) wird jedes Prüfungsmodul **dreimal**
vertieft. Über alle 60 Einheiten ergibt das:

| Modul     | Einheiten gesamt |
|-----------|------------------:|
| Lesen     | 15               |
| Hören     | 15               |
| Schreiben | 15               |
| Sprechen  | 15               |

→ siehe [Übersicht](/uebersicht/) für die genaue Zuordnung.
